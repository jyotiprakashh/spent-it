Inline SVG icon (Lucide outline). Use everywhere an icon is needed — never emoji or runtime icon fonts.

\`\`\`jsx
<Icon name="wallet" size={20} color="var(--color-primary)" />
<Icon name="groceries" /> {/_ semantic alias _/}
\`\`\`

Names accept raw Lucide stems (shopping-cart, chart-pie, scan-face…) or SpentIt aliases (groceries, salary, biometric, backup, restore, budgets, analytics). Stroke 2, round caps, 24×24 viewBox.
